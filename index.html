Guia de bolso

Comandos Essenciais

git init

Comando de inicialização>

git add .

adiciona alterações

git commit -m "[mensagem de commit]"

Comitar

git push -u origin main

Mudanças feitas para aparecer na web site

git fetch

Verifica se o repositório remoto tem modificações em relação ao local

git pull

É usado para baixar conteúdo de um repositório remoto e atualizar imediatamente seu repositório local

git clone [link do repositório]

Clonagem

git remote add origin[link do repositório

Conecta o repositório local ao repositório remoto

Não esquecer de dar espaço no "add git ."
